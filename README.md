# ПростоТекст — Агентный уровень (Вариант 9)

Веб-сервис агентного уровня распределённой информационной системы упрощения сложных научных и технических текстов **«ПростоТекст»** (вариант 9).

* **Вуз и кафедра:** МГТУ им. Н.Э. Баумана, кафедра ИУ5 «Системы обработки информации и управления»
* **Дисциплина:** Сетевые технологии в АСОИУ
* **Группа:** ИУ5-75Б
* **Исполнитель:** Герасимович Н. И.

## Назначение и возможности

* Приём исходного сложного текста от транспортного уровня по HTTP (`POST /transfer`).
* Потоковое упрощение текста с помощью локальной языковой модели `Qwen2.5-3B-Instruct` через Ollama без обращения к внешним облачным API.
* Формирование смысловых частей ответа по 2–3 предложения по мере генерации.
* Побайтовая UTF-8-сегментация сериализованного JSON (`SimplifiedPartMessage`) на фрагменты размером не более 1000 байт без повреждения многобайтовых символов.
* Последовательная отправка сегментов на транспортный уровень (`POST /simplify/transfer`) и передача финального маркера завершения (`isFinal: true`).
* Автоматическая OpenAPI/Swagger-документация (`/docs`) и проверка готовности модели (`/health`).

## Стек технологий

* **Язык и фреймворк:** Python 3.10+, FastAPI, Uvicorn
* **Валидация и HTTP-клиент:** Pydantic, Pydantic-Settings, HTTPX
* **Локальная LLM:** Ollama, модель `Qwen2.5-3B-Instruct` (`qwen2.5:3b`)
* **Тестирование:** Pytest, Pytest-Asyncio

## Установка и настройка

### 1. Установка Ollama и модели

Установите [Ollama](https://ollama.com/) и загрузите локальную модель `Qwen2.5-3B-Instruct`:

```bash
ollama pull qwen2.5:3b
ollama list
```

### 2. Виртуальное окружение и зависимости

**Windows (PowerShell):**
```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

**Linux / macOS:**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

### 3. Переменные окружения (`.env`)

| Параметр | Значение по умолчанию | Описание |
| :--- | :--- | :--- |
| `HOST` | `127.0.0.1` | Адрес прослушивания (`0.0.0.0` для работы в сети) |
| `PORT` | `8000` | Порт агентного сервиса |
| `TRANSPORT_TRANSFER_URL` | `http://127.0.0.1:8080/simplify/transfer` | Адрес метода приёма сегментов транспортного уровня |
| `OLLAMA_BASE_URL` | `http://127.0.0.1:11434` | Адрес локального сервера Ollama |
| `OLLAMA_MODEL` | `qwen2.5:3b` | Идентификатор модели в Ollama |
| `MAX_SEGMENT_BYTES` | `1000` | Предельный размер `payload` сегмента в байтах UTF-8 |
| `SENTENCES_PER_PART` | `2` | Количество предложений в одной передаваемой части ответа |
| `TRANSPORT_TIMEOUT_SEC` | `15.0` | Таймаут HTTP-запроса к транспортному уровню (с) |
| `OLLAMA_TIMEOUT_SEC` | `120.0` | Таймаут генерации ответа LLM (с) |

## Запуск

### Локальная проверка с заглушкой транспорта

В первом терминале запустите заглушку транспортного уровня (порт `8080`):
```powershell
.\.venv\Scripts\python.exe mock_transport.py
```

Во втором терминале запустите агентный сервис (порт `8000`):
```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

После запуска проверьте готовность сервиса и модели по адресу `http://127.0.0.1:8000/health` и откройте интерактивную документацию Swagger на `http://127.0.0.1:8000/docs`.

### Подключение к реальному транспортному уровню

1. Остановите `mock_transport.py`.
2. Укажите в `.env` сетевой адрес транспортного сервиса (`TRANSPORT_TRANSFER_URL=http://<IP_транспорта>:8080/simplify/transfer`) и `HOST=0.0.0.0`.
3. Запустите сервис с прослушиванием всех сетевых интерфейсов (при запуске на одной машине с прикладным уровнем выберите другой порт, например `8002`, так как прикладной сервер также использует `8000`):
   ```powershell
   .\.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000
   ```

## Основные HTTP-методы

| Метод | Описание | Коды ответов |
| :--- | :--- | :--- |
| `POST /transfer` | Приём исходного сложного текста (`sender`, `sendTime`, `complexText`) и запуск потокового упрощения | `200`, `400`, `500` |
| `POST /send` | Валидация и отправка одного сегмента (`sendTime`, `totalSegments`, `segmentNumber`, `payload` ≤ 1000 Б) на транспорт | `200`, `400`, `502` |
| `GET /health` | Проверка работоспособности сервиса и доступности модели в Ollama | `200` |

## Тестирование

Запуск автоматизированных тестов:
```powershell
.\.venv\Scripts\python.exe -m pytest -v
```

Набор тестов проверяет соблюдение лимита 1000 байт в UTF-8, сохранность многобайтовых символов при разбиении, группировку предложений с учётом сокращений, валидацию входного JSON (`400`), обработку недоступности Ollama (`500`) и потоковую отправку частей с финальным маркером `isFinal: true`.
